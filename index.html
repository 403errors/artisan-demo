Project Overview

This repository serves as a demonstration and testing harness for Artisan, an autonomous AI-driven engineering pipeline that transforms GitHub issues into verified pull requests.

Gate 1: Intake & Plan

Analyzes requirements, identifies necessary file changes, and constructs an execution plan.

Gate 2: Execute & Verify

Applies code changes, writes test cases, runs verification checks, and publishes a pull request.

Getting Started & Local Setup

To view or run this static landing page locally, use any of the following methods:

# Option 1: Using Python
python3 -m http.server 8000

# Option 2: Using Node.js
npx serve .

Once running, navigate to http://localhost:8000 or open index.html directly in your web browser.
