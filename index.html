Artisan Demo

Powered by Gemini and Vertex AI

A demonstration repository showcasing autonomous issue triage, implementation planning, code execution, and pull request generation.

About the Project

Artisan is an autonomous software engineering agent designed to resolve repository issues end-to-end. Built with Google Gemini and Vertex AI, Artisan monitors issues, performs structured reasoning, applies necessary edits, and submits comprehensive Pull Requests.

Autonomous Pipeline Workflow

When an issue is created in this repository, Artisan activates a two-stage pipeline:

Gate 1: Intake & Triage

  • Validates issue requirements
  • Extracts problem statements & scope
  • Verifies safety & security bounds

Gate 2: Autonomous Execution

  • Plan: Formulates actionable steps
  • Execute: Modifies codebase files
  • Verify: Validates syntax & tests
  • PR: Submits review-ready Pull Request

Local Development & Setup

To run this landing page locally, serve it using any standard static file server:

# Using Python 3
python3 -m http.server 8000

# Using Node.js
npx serve .

Then open http://localhost:8000 in your browser.

Triggering Artisan

Open a new issue in this repository describing a bug fix or feature. Artisan will autonomously inspect the issue, run its intake verification, formulate an execution plan, and submit a Pull Request with the resolution.
