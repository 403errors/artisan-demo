Project Overview

Artisan is an autonomous software engineering agent system engineered to turn user-reported issues into verified, high-quality pull requests without human intervention.

This demo repository serves as a live testbed to showcase and exercise the end-to-end autonomous lifecycle during the All Things Agentic Hackathon 2026.

Autonomous Pipeline Architecture

Gate 1: Intake & Triage

Analyzes incoming issue descriptions, validates reproducibility, and defines clear acceptance criteria.

Gate 2: Planning

Formulates a precise, multi-step execution plan specifying files, tests, and dependencies to modify.

Gate 2: Execution

Coding agent applies incremental code edits, adds test coverage, and updates documentation.

Gate 2: Verification & PR

Validates code integrity, runs tests, and opens an automated Pull Request with a clear change summary.

Technology Stack

  • LLM & Reasoning: Google Gemini models for deep contextual code analysis and planning.
  • Cloud Platform: Vertex AI providing robust, enterprise-grade AI infrastructure.
  • Agent Framework: Artisan multi-gate autonomous execution agent.
  • Version Control: Automated GitHub integration for branch management and PR creation.

Presentation & Demonstration Details

During the hackathon presentation, Artisan demonstrates real-time issue processing:

  • Filing an issue triggers automated webhook ingestion.
  • Artisan plans and implements the necessary changes directly against the repository checkout.
  • Syntax, test cases, and markup integrity checks run automatically before submitting a pull request.
